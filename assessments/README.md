# Проверочные материалы · 7 класс · Алгебра · Макарычев

Раздел содержит печатные web-комплекты самостоятельных и контрольных работ для всех семи тематических страниц учебной линии `7-algebra-makarychev`.

## Формат

Для каждой темы предусмотрены:

- `independent.html` — самостоятельная работа, 6 равноценных вариантов;
- `control.html` — контрольная работа, 6 равноценных вариантов;
- `data.js` — задания, ответы, решения, баллы и карта навыков.

Общие `assessment-page.js` и `assessment-page.css` отвечают за выбор варианта, режим учителя, критерии и печать/PDF.

Самостоятельная работа содержит 8 заданий и оценивается в 14 баллов. Контрольная работа содержит 10 заданий и оценивается в 20 баллов. Задания распределены по уровням A–C: базовое владение, уверенное применение, перенос/обоснование.

## Источники

Основной предметный ориентир: Ю. Н. Макарычев, Н. Г. Миндюк, К. И. Нешков, С. Б. Суворова, «Математика. Алгебра. 7 класс. Базовый уровень», 2024.

Диагностический ориентир: Ю. А. Глазков, М. Я. Гаиашвили, «Самостоятельные и контрольные работы по алгебре. 7 класс», 2015.

Из СиКР используется карта контролируемых навыков и общая идея разноуровневой проверки. Формулировки, числа, контексты и наборы данных в KTP разработаны заново.

## QA

Для каждого из 84 вариантов проверяются:

- одинаковое число заданий и одинаковый максимум баллов внутри типа работы;
- тематическое соответствие странице KTP;
- наличие ответов;
- наличие ключевых шагов для задач повышенной сложности;
- отсутствие деления на нуль и неоднозначных условий;
- корректность построенных уравнений и систем;
- пригодность для печати на A4.
