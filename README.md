# KTP 3.0 — КТП 2026/27

Интерактивная система календарно-тематического планирования для 5–11 классов. Версия 3.0 развивает исходную таблицу в рабочий контур **«план → факт → корректировка»** и постепенно превращает тематические страницы в самостоятельные учебные web-модули.

## Что умеет KTP 3.0

- календарная шкала на 34 учебные недели и 17 учебных линий;
- представления **Обзор**, **КТП**, **Сегодня**;
- плановые и фактические статусы тем, фактические даты и заметки;
- drag-and-drop перепланирование, резерв и прогноз завершения;
- экспорт / импорт состояния JSON и сохранение в `localStorage`;
- отдельная адресная web-страница для каждой тематической ячейки;
- подключаемый слой предметного контента без дублирования общего HTML;
- отдельные цифровые лаборатории для тем, где исследование параметров улучшает понимание;
- печатные самостоятельные и контрольные работы с несколькими вариантами для наполненных учебных линий.

## Страницы тем

Адресная схема:

```text
topics/<учебная-линия>/<номер-темы>.html
```

HTML-файл темы остаётся лёгким контейнером. Он подключает данные KTP, предметный content-файл и общий renderer `topics/topic-page.js`.

Полноценный модуль может содержать:

- prerequisites и входную самопроверку;
- образовательные цели и ожидаемые результаты;
- карту темы;
- теорию и формулы;
- разобранные примеры;
- типичные ошибки;
- тренировку уровней A–D;
- мини-диагностику;
- домашнюю работу и ответы;
- блок «Что нужно запомнить»;
- ссылку на отдельную цифровую лабораторию;
- ссылки на самостоятельную и контрольную работы.

Первая полностью наполненная учебная линия — **7 класс · Алгебра · Макарычев**. Контент основан на актуальном учебнике Макарычева 2024 года; сборник самостоятельных и контрольных работ используется как дополнительный диагностический ориентир. Внутренняя карта источников хранится в `content/7-algebra-makarychev/content-map.md`.

## Проверочные материалы

Для всех семи страниц линии `7-algebra-makarychev` созданы отдельные комплекты:

```text
assessments/7-algebra-makarychev/<номер-темы>/
├── independent.html
├── control.html
└── data.js
```

Каждая самостоятельная и каждая контрольная работа содержит **6 равноценных вариантов**. Web-страница позволяет выбрать один вариант, показать сразу все шесть, включить ответы и критерии и распечатать материал / сохранить его как PDF. Сами задания хранятся отдельно от renderer и сформулированы специально для KTP.

## Архитектура

Проект не требует сборки и внешних библиотек:

```text
/
├── index.html
├── css/
│   ├── app.css
│   └── topic-links.css
├── js/
│   ├── data.js
│   ├── storage.js
│   ├── app.js
│   └── topic-links.js
├── content/
│   ├── registry.js
│   └── <учебная-линия>/
│       ├── 01.js
│       ├── 02.js
│       └── ...
├── labs/
│   └── <учебная-линия>/
│       └── <topic-number>/
│           ├── index.html
│           ├── app.js
│           └── style.css
├── assessments/
│   ├── assessment-page.js
│   ├── assessment-page.css
│   ├── topic-links.js
│   └── <учебная-линия>/
│       └── <topic-number>/
│           ├── independent.html
│           ├── control.html
│           └── data.js
└── topics/
    ├── index.html
    ├── topic-page.css
    ├── topic-page.js
    └── <учебная-линия>/
        └── NN.html
```

`content/registry.js` создаёт единый реестр `window.KTP_CONTENT`. Уникальное содержание темы хранится отдельно от UI и состояния. Если content-файл отсутствует, общий renderer сохраняет прежний режим адресной заглушки, поэтому архитектура совместима с ещё не наполненными линиями.

Цифровая лаборатория является отдельной страницей и связывается с релевантной темой ссылкой; sticky-панели лаборатории внутри основного урока не используются.

Проверочные материалы также используют общий renderer. Тематические страницы подключают `assessments/topic-links.js`, который добавляет ссылки только для тех страниц, где соответствующие комплекты существуют.

## Использование

1. Откройте `index.html` или опубликуйте `main` через GitHub Pages.
2. Кликните по теме, чтобы открыть карточку план/факт и изменить состояние.
3. Нажмите `↗` или **«Открыть страницу темы»**, чтобы перейти к учебному модулю.
4. В блоке **«Проверочные материалы»** откройте самостоятельную или контрольную работу, выберите вариант и используйте **«Печать / PDF»**.
5. Используйте **«Перепланирование»** для изменения календарных границ.
6. Используйте **«Сегодня»** для оперативной работы и **«Обзор»** для контроля прогресса.
7. Периодически экспортируйте состояние JSON для резервной копии.

## Хранение данных

Рабочие отметки, изменения плана, фактические даты, заметки и журнал сохраняются локально в браузере под ключом `ktp-2026-27-v3`. Исходный учебный план остаётся в `js/data.js`; пользовательские корректировки хранятся поверх базовой модели.
