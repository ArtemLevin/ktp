# KTP 3.0 — КТП 2026/27

Интерактивная система календарно-тематического планирования для 5–11 классов. KTP 3.0 объединяет календарный контур **«план → факт → корректировка»** с самостоятельными образовательными web-модулями.

## Возможности

- календарная шкала на 34 учебные недели и 17 учебных линий;
- представления **Обзор**, **КТП**, **Сегодня**;
- статусы тем, фактические даты, заметки и перепланирование;
- экспорт / импорт состояния JSON и хранение в `localStorage`;
- отдельная адресная web-страница каждой тематической ячейки;
- подключаемый предметный контент без дублирования общего HTML;
- отдельные цифровые лаборатории для тем, где интерактив улучшает понимание;
- самостоятельные и контрольные работы с несколькими вариантами;
- поурочная декомпозиция крупных тем на отдельные адресные модули.

## Страницы тем

Адресная схема:

```text
topics/<учебная-линия>/<номер-темы>.html
```

HTML темы остаётся лёгким контейнером: он подключает данные KTP, предметный content-файл и общий renderer `topics/topic-page.js`. Наполненная тема может содержать prerequisites, цели, карту темы, теорию, примеры, типичные ошибки, тренировку, диагностику, домашнюю работу, ответы и ссылку на отдельную цифровую лабораторию.

Первая полностью наполненная учебная линия — **7 класс · Алгебра · Макарычев**. Основной источник — учебник Макарычева 2024 года; сборник самостоятельных и контрольных работ используется как диагностический ориентир. Карта источников хранится в `content/7-algebra-makarychev/content-map.md`.

## Поурочная подготовка

Крупная тема может иметь отдельную серию уроков:

```text
lessons/<учебная-линия>/<номер-темы>/
├── index.html
├── series.js
├── 01.html
├── 02.html
├── ...
└── data/
    ├── 01.js
    ├── 02.js
    └── ...
```

Общие renderer и стили находятся в `lessons/lesson-page.js`, `lessons/lesson-index.js` и `lessons/lesson-page.css`. Скрипт `lessons/topic-links.js` добавляет переход на серию со страницы релевантной темы.

Первая завершённая серия — `7-algebra-makarychev/01`: **18 уроков / 6 учебных недель** по теме «Выражения, тождества, уравнения». Каждый урок имеет теорию, примеры, тренировку, домашнюю работу, самостоятельную работу в 6 вариантах и поурочный контроль в 6 вариантах. Подробности архитектуры: `lessons/README.md`.

## Проверочные материалы тем

Для семи тематических страниц линии `7-algebra-makarychev` существуют отдельные комплекты:

```text
assessments/7-algebra-makarychev/<номер-темы>/
├── independent.html
├── control.html
└── data.js
```

Каждая тематическая самостоятельная и контрольная работа содержит 6 равноценных вариантов. Общий renderer поддерживает выбор варианта, ответы, критерии и печать / PDF.

## Архитектура

Проект работает без сборки и внешних библиотек:

```text
/
├── index.html
├── css/
├── js/
├── content/
│   ├── registry.js
│   └── <учебная-линия>/
├── topics/
│   ├── topic-page.js
│   ├── topic-page.css
│   └── <учебная-линия>/NN.html
├── lessons/
│   ├── lesson-page.js
│   ├── lesson-index.js
│   ├── lesson-page.css
│   ├── topic-links.js
│   └── <учебная-линия>/<номер-темы>/
├── assessments/
│   ├── assessment-page.js
│   ├── assessment-page.css
│   └── <учебная-линия>/<номер-темы>/
└── labs/
    └── <учебная-линия>/<номер-темы>/
```

Учебный контент, состояние KTP, UI и цифровые лаборатории разделены. Если предметный content-файл отсутствует, тематический renderer сохраняет режим адресной заглушки.

Цифровые лаборатории размещаются отдельными web-страницами. Поурочные серии также используют отдельные адресные страницы; общий HTML и логика не копируются между уроками.

## Использование

1. Откройте `index.html` или опубликованную версию KTP.
2. Откройте нужную тематическую ячейку и затем адресную страницу темы.
3. Для первой темы алгебры 7 класса используйте блок **«Поурочная подготовка»**, чтобы перейти к каталогу 18 уроков.
4. На странице урока переходите между соседними уроками, раскрывайте ответы после попытки и выбирайте вариант самостоятельной или поурочного контроля.
5. Для тематической проверки используйте блок **«Проверочные материалы»**.
6. Статусы, фактические даты и заметки редактируйте на основной странице KTP.
7. Периодически экспортируйте состояние JSON для резервной копии.

## Хранение данных

Рабочие отметки, изменения плана, фактические даты, заметки и журнал сохраняются локально в браузере под ключом `ktp-2026-27-v3`. Исходный учебный план хранится в `js/data.js`; пользовательские корректировки записываются поверх базовой модели.
