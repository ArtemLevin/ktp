# КТП 2026/27

Интерактивный web-эквивалент календарно-тематического планирования на 2026/27 учебный год по исходной таблице.

## Возможности

- календарная шкала на 34 учебные недели;
- 17 строк КТП для 5–11 классов;
- фильтры по классу, предмету и линии учебника;
- полнотекстовый поиск по темам;
- автоматическая подсветка текущей учебной недели;
- карточка темы по клику;
- локальная отметка пройденных тем (`localStorage`);
- печать / экспорт в PDF средствами браузера;
- адаптивная горизонтальная прокрутка и sticky-заголовки.

## Запуск

Проект автономный и не требует сборки. Откройте `index.html` в браузере или включите GitHub Pages для ветки `main`.
