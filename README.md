# KTP 3.0 — КТП 2026/27

Интерактивная система календарно-тематического планирования и учебных web-модулей для математики 5–11 классов. KTP 3.0 соединяет календарный контур **«план → факт → корректировка»** с тематическими страницами, поурочной подготовкой, проверочными материалами и цифровыми лабораториями.

Актуальность документации: **09.09.2026**.

## Основные возможности

- календарная шкала на 34 учебные недели и 17 учебных линий;
- представления **Обзор**, **КТП**, **Сегодня**;
- плановые и фактические статусы, даты и заметки;
- drag-and-drop перепланирование, резерв и прогноз завершения;
- экспорт / импорт JSON и хранение рабочего состояния в `localStorage`;
- адресная страница каждой тематической ячейки;
- подключаемый предметный content-слой без дублирования общего HTML;
- поурочная декомпозиция тематических серий;
- самостоятельные и контрольные работы в 6 вариантах;
- reusable SVG-layer для учебных геометрических чертежей;
- отдельные цифровые лаборатории только там, где интерактивная модель усиливает понимание.

## Тематические страницы

Адресная схема: `topics/<учебная-линия>/<номер-темы>.html`. HTML темы остаётся лёгким контейнером и подключает календарные данные, content registry, предметный content и общий renderer.

Полностью опубликованы все тематические модули математики 5–6 классов и пяти основных алгебраических линий 7–11 классов.

В `7-geometry-atanasyan` опубликованы:

- `01` **«Начальные геометрические сведения»** — глава I, §§1–6, пп. 1–13;
- `02` **«Треугольники»** — глава II, §§1–4, пп. 14–23;
- `03` **«Параллельные прямые»** — глава III, §§1–2, пп. 24–29;
- `04` **«Соотношения между сторонами и углами треугольника»** — глава IV, §§1–4, пп. 30–38; п. 36* рассматривается как дополнительный материал.

В теме 04 сохранена последовательность конкретного издания Атанасяна: сумма углов и внешний угол → классификация треугольников → соотношения между сторонами и углами → признак равнобедренного треугольника → неравенство треугольника → свойства и признаки прямоугольных треугольников → расстояния → построения. В QA закреплены границы введения обратных утверждений и условие существования треугольника при построении по трём сторонам.

Source mapping линии хранится в `content/7-geometry-atanasyan/content-map.md`.

## Поурочная подготовка

```text
lessons/<учебная-линия>/<номер-темы>/
├── index.html
├── series.js
├── NN.html
└── data.js / data/ / packed-*.js
```

Общий UI: `lessons/lesson-page.js`, `lessons/lesson-index.js`, `lessons/lesson-page.css`, `lessons/series-adapter.js`, `lessons/global-numbering.js`.

Для 5 и 6 классов опубликовано по **170 уроков**; для каждой из пяти завершённых алгебраических линий — по **102 урока**. В геометрии 7 класса опубликованы уроки **1–47 из 68**.

Каждый полноценный урок содержит цели, prerequisites, компактную теорию, минимум два разобранных примера, типичные ошибки, тренировку, обязательную и дополнительную домашнюю работу, самостоятельную в 6 вариантах, поурочный контроль в 6 вариантах и итоговые тезисы.

Геометрические уроки используют `geometry/lesson-geometry.js` и общий `geometry/geometry-scene.js`. В теме 04 опубликованы десять reusable сцен для углов треугольника, внешнего угла, соотношения стороны и угла, неравенства треугольника, прямоугольных треугольников, расстояния и построения.

Актуальная карта слоя: `assessments/README.md`.

## Геометрический rendering layer

Каталог `geometry/` хранит общий zero-build SVG runtime для учебных чертежей. Поддерживаются точки, прямые, лучи, отрезки, углы, окружности, многоугольники, отметки равенства, параллельности и прямого угла.

Тематические страницы передают сцены через `geometryScenes` в content-объекте. Поурочные модули используют `KTP_LESSON_SERIES.geometryScenes`; адаптер `geometry/lesson-geometry.js` связывает их с общим renderer. Исследовательские модели с управляемыми параметрами выносятся в `labs/`.

## Цифровые лаборатории

Для 5 класса опубликованы четыре лаборатории: `number-line`, `area-volume`, `fraction-model`, `protractor`.

Для 6 класса опубликованы четыре лаборатории: `average-percent`, `proportion`, `signed-number-line`, `coordinate-plane`.

Для первых четырёх тем геометрии 7 класса отдельные лаборатории пока не требуются: data-driven SVG-сцены поддерживают чтение чертежа, доказательство и построительные шаги без лишнего управления параметрами.

## Definition of Done для учебной серии

Серия считается готовой к merge, когда содержание соответствует KTP и учебнику, теория достаточна для базовой тренировки, примеры и ответы проверены, упражнения корректны, навигация работает, SVG-чертежи соответствуют условию, мобильная и печатная версии пригодны, QA зелёный и документация отражает фактическое состояние.
