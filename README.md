# KTP 3.0 — КТП 2026/27

Интерактивная система календарно-тематического планирования и учебных web-модулей для математики 5–11 классов. KTP 3.0 соединяет календарный контур **«план → факт → корректировка»** с тематическими страницами, поурочной подготовкой, проверочными материалами и цифровыми лабораториями.

Актуальность документации: **11.09.2026**.

## Основные возможности

- календарная шкала на 34 учебные недели и 17 учебных линий;
- представления **Обзор**, **КТП**, **Сегодня**;
- плановые и фактические статусы, даты и заметки;
- drag-and-drop перепланирование, резерв и прогноз завершения;
- экспорт / импорт JSON и хранение рабочего состояния в `localStorage`;
- адресная страница каждой тематической ячейки;
- подключаемый предметный content-слой без дублирования общего HTML;
- поурочная декомпозиция тематических серий;
- самостоятельные и контрольные работы в 6 вариантах;
- reusable SVG-layer для учебных геометрических чертежей;
- отдельные цифровые лаборатории там, где интерактивная модель усиливает понимание.

## Геометрический rendering layer

Каталог `geometry/` хранит общий zero-build SVG runtime для учебных чертежей. Поддерживаются точки, прямые, лучи, отрезки, углы, окружности, многоугольники, отметки равенства, параллельности и прямого угла.

Тематические страницы передают сцены через `geometryScenes` в content-объекте. Поурочные модули используют `KTP_LESSON_SERIES.geometryScenes`; адаптер `geometry/lesson-geometry.js` связывает их с общим renderer. Исследовательские модели с управляемыми параметрами выносятся в `labs/`.

## Definition of Done для учебной серии

Серия считается готовой к merge, когда содержание соответствует KTP, учебнику и нормативным границам, теория достаточна для базовой тренировки, примеры и ответы проверены, упражнения корректны, навигация работает, SVG-чертежи соответствуют условиям, мобильная и печатная версии пригодны, QA зелёный и документация отражает фактическое состояние.
