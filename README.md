# KTP 3.0 — КТП 2026/27

Интерактивная система календарно-тематического планирования для 5–11 классов. Версия 3.0 развивает исходную таблицу в рабочий контур **«план → факт → корректировка»**.

## Что умеет KTP 3.0

- календарная шкала на 34 учебные недели и 17 учебных линий;
- три рабочих представления: **Обзор**, **КТП**, **Сегодня**;
- плановые и фактические статусы тем: запланировано, в работе, пройдено, перенесено, пропущено;
- фиксация фактических дат начала и завершения;
- автоматический расчёт прогресса и отклонения от календарного плана;
- оценка доступного резерва и того, покрывает ли он текущее отставание;
- ориентировочный прогноз даты завершения программы на основе фактического темпа;
- drag-and-drop перепланирование тем на временной шкале;
- режим автоматического сдвига последующих тем с поглощением изменения резервом;
- отмена последнего перепланирования;
- журнал изменений;
- заметки преподавателя к каждой теме;
- отдельный операционный экран **«Сегодня»** с текущей плановой и фактической темой;
- сводный dashboard по всем учебным линиям;
- группировка по классам, режим фокуса, поиск и фильтры;
- навигация по месяцам и мини-карта учебного года;
- компактный / комфортный режим плотности;
- экспорт и импорт состояния в JSON;
- перенос отметок выполнения из локального состояния KTP 2.0;
- сохранение рабочего состояния в `localStorage`;
- печатное представление.

## Архитектура

Проект не требует сборки и внешних библиотек:

```text
/
├── index.html
├── css/
│   └── app.css
└── js/
    ├── data.js       # учебный план и календарная модель
    ├── storage.js    # localStorage, история, import/export
    └── app.js        # timeline, dashboard, plan/fact, drag-and-drop
```

Разделение данных, хранилища и UI позволяет в дальнейшем подключить backend или синхронизацию с другими сервисами без переноса учебного плана из разметки страницы.

## Использование

1. Откройте `index.html` или опубликуйте ветку `main` через GitHub Pages.
2. Кликните по теме, чтобы открыть карточку план/факт, изменить статус, фактические даты или добавить заметку.
3. Включите **«Перепланирование»**, затем перетащите тему по временной шкале. При включённой опции последующие темы сдвигаются вместе с ней, а конечный резерв поглощает изменение.
4. Используйте **«Сегодня»** для ежедневной работы и **«Обзор»** для контроля отставаний, резерва и прогноза.
5. Периодически используйте **«Экспорт»**, если нужно перенести локальное состояние в другой браузер или сохранить резервную копию.

## Хранение данных

Рабочие отметки, изменения плана, фактические даты, заметки и журнал сохраняются локально в браузере под ключом `ktp-2026-27-v3`. Исходный учебный план остаётся в `js/data.js` и не изменяется: пользовательские корректировки хранятся поверх базовой модели.
