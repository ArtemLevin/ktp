# KTP 3.0 — КТП 2026/27

Интерактивная система календарно-тематического планирования и учебных web-модулей для математики 5–11 классов. KTP 3.0 соединяет календарный контур **«план → факт → корректировка»** с тематическими страницами, поурочной подготовкой, проверочными материалами и отдельными цифровыми лабораториями.

Актуальность документации: **06.09.2026**.

## Основные возможности

- календарная шкала на 34 учебные недели и 17 учебных линий;
- представления **Обзор**, **КТП**, **Сегодня**;
- плановые и фактические статусы, даты и заметки;
- drag-and-drop перепланирование, резерв и прогноз завершения;
- экспорт / импорт JSON и хранение рабочего состояния в `localStorage`;
- отдельная адресная страница каждой тематической ячейки;
- подключаемый предметный content-слой без дублирования общего HTML;
- поурочная декомпозиция тематических серий;
- самостоятельные и контрольные работы в 6 вариантах;
- отдельные цифровые лаборатории там, где исследовательская модель улучшает понимание.

## Источники истины для статусов

Фактическая готовность определяется по коду:

1. `js/data.js` — полный реестр 17 линий, названия тем и календарные границы;
2. `content/<учебная-линия>/` — полноценные тематические content-модули;
3. `lessons/topic-links.js` и `lessons/<учебная-линия>/` — реально опубликованные поурочные серии;
4. `assessments/topic-links.js` и `assessments/<учебная-линия>/` — тематические самостоятельные и контрольные работы;
5. `labs/<учебная-линия>/` — опубликованные цифровые лаборатории.

При merge, который меняет готовность линии, одновременно обновляются сводная документация и профильные README соответствующих слоёв.

## Страницы тем

Адресная схема:

```text
topics/<учебная-линия>/<номер-темы>.html
```

Тематический HTML остаётся лёгким контейнером и подключает `js/data.js`, `js/storage.js`, `content/registry.js`, предметный content-файл и общий `topics/topic-page.js`.

Полноценная тема может содержать prerequisites, входную самопроверку, цели и ожидаемые результаты, карту темы, теорию, определения и формулы, разобранные примеры, типичные ошибки, тренировку A–D, мини-диагностику, домашнюю работу, ответы, итоговые тезисы, ссылки на лабораторию, проверочные материалы и поурочную серию.

В 5 классе полностью опубликованы первые две темы: `topics/5-math-vilenkin/01.html` **«Натуральные числа»** и `topics/5-math-vilenkin/02.html` **«Сложение и вычитание натуральных чисел»**. Первая согласована с частью 1, §1, пунктами 1–7 учебника Виленкина и дополнена требуемым ФРП округлением натуральных чисел; вторая соответствует части 1, §2, пунктам 8–11.

## Цифровые лаборатории

Лаборатория всегда является отдельной web-страницей и создаётся только при самостоятельной исследовательской ценности модели.

К существующим лабораториям пяти завершённых алгебраических линий добавлена первая лаборатория 5 класса:

```text
labs/5-math-vilenkin/number-line/
```

Она позволяет менять цену деления и границы шкалы, перетаскивать точки A и B, исследовать сравнение координат и расстояние между точками, а также тренировать постановку точки по заданной координате.

Для темы 02 отдельная лаборатория не создавалась: свойства действий, выражения и уравнения эффективнее отрабатываются через пошаговые примеры и тренировку.

`content/registry.js` создаёт единый `window.KTP_CONTENT`. Если content-файл темы ещё отсутствует, общий renderer сохраняет режим адресной заглушки, поэтому линии можно наполнять последовательно без изменения календарного ядра.

Пять завершённых алгебраических линий защищены общим CI-контуром `.github/workflows/reference-lines-regression-qa.yml`; локальный gate — `node scripts/qa-reference-lines.mjs`. Он проверяет 5 линий, 35 тематических серий и 510 уроков.

Для линии 5 класса действуют три дополнительных gate:

```bash
node scripts/qa-grade5-vilenkin-plan.mjs
node scripts/qa-grade5-vilenkin-topic01.mjs
node scripts/qa-grade5-vilenkin-topic02.mjs
```

Первый защищает 170-часовую календарно-поурочную модель. QA темы 01 проверяет 18 уроков, 216 поурочных assessment-вариантов, тематические 6+6 вариантов и цифровую лабораторию. QA темы 02 проверяет 17 уроков курса 19–35, 204 поурочных assessment-варианта, тематические 6+6 вариантов, глобальную нумерацию, суммы баллов, ответы, JS-синтаксис и локальные ссылки.

## Definition of Done для учебной серии

Перед merge проверяются:

- соответствие теме KTP, учебнику и уровню класса;
- корректность формул, вычислений, условий, единиц и ответов;
- количество и уникальность уроков;
- наличие 6 вариантов самостоятельной и 6 вариантов поурочного контроля;
- корректность сумм баллов;
- JS-синтаксис и загрузка данных;
- переходы между уроками, темами, assessments и labs;
- мобильная компоновка и печатный режим;
- отсутствие временных QA-файлов и длинных дословных заимствований;
- синхронизация документации с фактическим состоянием `main`.

## Использование

1. Откройте `index.html` или опубликованный GitHub Pages.
2. Выберите тему и откройте её адресную страницу.
3. Используйте блок **«Поурочная подготовка»** для перехода к занятиям.
4. Решайте тренировку до раскрытия ответов.
5. Открывайте лабораторию из релевантной темы или урока.
6. Для опубликованного assessment-комплекта выберите самостоятельную или контрольную работу и нужный вариант.
7. Используйте **«Перепланирование»**, **«Сегодня»** и **«Обзор»** для работы с календарём.
8. Периодически экспортируйте состояние JSON для резервной копии.

## Хранение данных

Рабочие отметки, изменения плана, фактические даты, заметки и журнал сохраняются локально в браузере под ключом `ktp-2026-27-v3`. Исходный учебный план находится в `js/data.js`; пользовательские корректировки хранятся поверх базовой модели.
