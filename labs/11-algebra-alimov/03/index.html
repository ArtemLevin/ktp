Исследовательские задания

  1. Выберите f(x)=x², a=0, b=3. Увеличивайте N и сравните сумму полос с точным значением 9.
  2. Выберите f(x)=x, a=−2, b=2. Почему интеграл равен 0, а геометрическая площадь положительна?
  3. Для f(x)=sin x установите a=0, b≈3,14. Сопоставьте результат с первообразной −cos x.
  4. Для f(x)=2−x возьмите интервал, пересекающий x=2. Найдите момент, когда интеграл и геометрическая площадь начинают различаться.
Ключевой вывод

Формула Ньютона—Лейбница вычисляет ориентированный интеграл F(b)−F(a). Если график проходит ниже Ox, геометрическую площадь получают разбиением в нулях функции и сложением модулей вкладов.
