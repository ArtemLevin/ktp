Исследовательский вопрос

Какая структурная деталь задачи сильнее всего влияет на выбор метода: фигура, положение вершины, прямой угол, координаты, вектор или тип преобразования?

Как пользоваться тренажёром

  1. Перед чтением поля «Аппарат» сформулируйте свой выбор.
  2. Переключите все десять сценариев и выпишите для каждого главный сигнал.
  3. Изменяйте параметр. Отделите то, что меняет только вычисления, от того, что меняет сам метод.
  4. Для двух сценариев придумайте альтернативный корректный метод.
  5. Выберите три сценария, в которых чаще ошибаетесь, и составьте мини-карту повторения.
Самодиагностика

Коды ошибок

READ

Неверно прочитана конфигурация.

SELECT

Выбран неподходящий аппарат.

COND

Не проверено условие теоремы.

ALG

Ошибка вычисления.

LOGIC

Разрыв доказательства.

CHECK

Нет финальной проверки.

Главный принцип

Сначала структура, затем формула

Числа меняют конкретный ответ. Тип фигуры, положение вершины, прямой угол, окружностная связь, координаты или вид преобразования определяют группу методов.
