# Поурочная линия · 10 класс · Алгебра · Алимов

Линия `10-algebra-alimov` содержит 102 урока по главам I–VII учебника Алимова и итоговому повторению.

- `01` — Действительные числа: 11 уроков, глобальные номера 1–11, недели 1–4, Глава I §§1–5.
- `02` — Степенная функция: 10 уроков, глобальные номера 12–21, недели 4–7, Глава II §§6–10*.
- `03` — Показательная функция: 10 уроков, глобальные номера 22–31, недели 8–11, Глава III §§11–14.
- `04` — Логарифмическая функция: 14 уроков, глобальные номера 32–45, недели 11–15, Глава IV §§15–20.
- `05` — Тригонометрические формулы: 16 уроков, глобальные номера 46–61, недели 16–21, Глава V §§21–32.
- `06` — Тригонометрические уравнения: 14 уроков, глобальные номера 62–75, недели 21–25, Глава VI §§33–37*.
- `07` — Тригонометрические функции: 15 уроков, глобальные номера 76–90, недели 26–30, Глава VII §§38–43*.
- `08` — Повторение курса 10 класса: 12 уроков, глобальные номера 91–102, недели 31–34, Итоговое повторение главы I–VII.

## Хранение данных серии

Из-за большого объёма 102 полноценных уроков данные каждой серии хранятся в автономном `data.js` как gzip-пакет в Base64. Общий `lessons/compressed-loader.js` использует встроенный браузерный `DecompressionStream`, восстанавливает исходный JS-реестр уроков и только после этого подключает общий renderer. Внешние библиотеки и сетевые запросы для распаковки не требуются; страницы сохраняют работу при локальном открытии файла в современном браузере.

Человекочитаемая поурочная карта хранится в `lesson-plan.md`. Сжатие касается только транспортного представления большого набора данных и не меняет разделение «учебный контент / UI / состояние».
