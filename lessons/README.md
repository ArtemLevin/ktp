# Поурочные модули KTP 3.0

Каталог `lessons/` хранит поурочную декомпозицию крупных тематических ячеек KTP. Один урок имеет собственный URL и использует общий renderer, поэтому учебный контент отделён от UI.

## Адресная схема

```text
lessons/<учебная-линия>/<номер-темы>/
├── index.html          # каталог уроков темы
├── series.js           # метаданные серии и точечные QA-коррекции
├── 01.html
├── 02.html
├── ...
└── data/
    ├── 01.js
    ├── 02.js
    └── ...
```

Общие файлы:

```text
lessons/
├── lesson-page.js      # renderer одного урока
├── lesson-index.js     # renderer каталога уроков
├── lesson-page.css     # общий адаптивный стиль
├── topic-links.js      # ссылка со страницы релевантной темы
└── series-adapter.js   # адаптация общих renderer'ов к серии и подключение лабораторий
```

## Завершённые серии

- `7-algebra-makarychev/01` — «Выражения, тождества, уравнения»: 18 уроков / 6 учебных недель.
- `7-algebra-makarychev/02` — «Функции»: 11 уроков / 4 учебные недели, глава II, §4–§5, пункты 11–16 учебника Макарычева 2024 года.
- `7-algebra-makarychev/03` — «Степень с натуральным показателем»: 12 уроков / 4 учебные недели, глава III, §6–§7, пункты 18–23; для графиков y=x² и y=x³ подключена отдельная цифровая лаборатория.

Каждый объект урока содержит номер, название, учебную неделю и источник; цели и prerequisites; теоретические блоки; разобранные примеры; типичные ошибки; тренировку; обязательную и дополнительную домашнюю работу; самостоятельную работу в 6 вариантах; поурочный контроль в 6 вариантах; итоговые тезисы. Для тем, где исследовательская модель улучшает понимание, урок может содержать ссылку на отдельную цифровую лабораторию.

`series.js` создаёт `window.KTP_LESSON_SERIES`, после чего `data/NN.js` добавляет один урок в массив `lessons`. Каталог темы загружает все файлы данных, а адресная страница урока — только нужный файл. `series-adapter.js` использует метаданные серии для количества уроков и добавляет отдельную ссылку на лабораторию, когда у урока есть `lab`.

## QA

Перед merge необходимо проверить:

1. количество уроков и уникальность `id`;
2. суммы баллов во всех вариантах;
3. ответы, проверки разобранных примеров и условия задач;
4. синтаксис общих JS-файлов и файлов данных;
5. переходы каталог → урок → соседний урок → тема KTP;
6. мобильную компоновку и печать;
7. отсутствие временных QA-файлов в `data/`;
8. корректность ссылок на отдельные цифровые лаборатории.
