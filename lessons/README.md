# Поурочные модули KTP 3.0

Каталог `lessons/` хранит поурочную декомпозицию крупных тематических ячеек KTP. Один урок имеет собственный URL и использует общий renderer, поэтому учебный контент остаётся отделён от UI.

## Адресная схема

```text
lessons/<учебная-линия>/<номер-темы>/
├── index.html          # каталог уроков темы
├── series.js           # метаданные серии и точечные QA-коррекции миграции
├── 01.html
├── 02.html
├── ...
└── data/
    ├── 01.js
    ├── 02.js
    └── ...
```

Общие файлы:

```text
lessons/
├── lesson-page.js      # renderer одного урока
├── lesson-index.js     # renderer каталога уроков
├── lesson-page.css     # общий адаптивный стиль
└── topic-links.js      # ссылка со страницы релевантной темы
```

## Первая серия

`7-algebra-makarychev/01` — тема «Выражения, тождества, уравнения», 18 уроков на 6 учебных недель.

Каждый объект урока содержит:

- номер, название, учебную неделю и источник;
- цели и prerequisites;
- теоретические блоки;
- разобранные примеры;
- типичные ошибки;
- тренировку;
- обязательную и дополнительную домашнюю работу;
- самостоятельную работу в 6 вариантах;
- поурочный контроль в 6 вариантах;
- итоговые тезисы.

`series.js` создаёт `window.KTP_LESSON_SERIES`, после чего `data/NN.js` добавляет один урок в массив `lessons`. Каталог темы загружает все файлы данных, а адресная страница урока — только нужный файл.

## QA

Перед merge необходимо проверить:

1. количество уроков и уникальность `id`;
2. суммы баллов во всех вариантах;
3. ответы, проверки разобранных примеров и условия задач;
4. синтаксис общих JS-файлов;
5. переходы каталог → урок → соседний урок → тема KTP;
6. мобильную компоновку и печать;
7. отсутствие временных QA-файлов в `data/`.
