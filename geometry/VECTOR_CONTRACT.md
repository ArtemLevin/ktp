# Пространственный вектор · контракт модели и изображения

`vector-math.js` — zero-build API `window.KTP_VECTOR_MATH`. Все точки и свободные векторы представлены строгими массивами из трёх конечных чисел `[x,y,z]`. Строки, неполные массивы, NaN, Infinity и переполнение отклоняются. Функции создают новые массивы; исходные данные не изменяются.

## Модель

```js
const V=window.KTP_VECTOR_MATH;
const ab=V.directedSegment('AB',[0,0,0],[1,2,2],'AB');
// {id, label, from, to, displacement:[1,2,2], length:3, zero:false}
const copy=V.translate(ab,[4,0,1]);
// copy.from=[4,0,1], copy.to=[5,2,3]; длина/направление сохранены
```

`directedSegment` вычисляет displacement и длину из концов. `translate` повторно вычисляет исходный отрезок из `from/to`, игнорируя возможные устаревшие производные поля.

Операции: `add(a,b)`, `subtract(a,b)`, `scale(a,k)`, `sum(vectors)`, `length(a)`, `isZero(a)`, `equal(a,b)`, `linearCombination(vectors,coefficients)`.

`relation(a,b)` возвращает `equal`, `collinear`, `codirected`, `opposed`, `directionDefined`. При нулевом аргументе коллинеарность и условная сонаправленность истинны (Атанасян, п. 63), `opposed=false`, `directionDefined=false`. Нуль определяется точным совпадением компонентов с 0: малый ненулевой вектор сохраняет направление и отличается от нуля при проверке равенства. Для двух ненулевых векторов допуск равен `EPS=1e-10`, умноженному на максимальный модуль компонента обоих векторов; это численная проверка, не символьное доказательство.

## Плоскость и разложение

- `coplanar(a,b,c)` проверяет тройку после приведения к общему началу, включая нули и коллинеарные пары.
- `plane(origin,a,b)` создаёт плоскость по двум неколлинеарным направлениям.
- `inPlane(model,value,asPoint=true)` проверяет точку; с `false` — свободный вектор. Плоскость пересчитывается по исходным направлениям.
- `parallelepiped(origin,[a,b,c])` требует некомпланарную тройку и возвращает восемь точек `O,A,B,C,AB,AC,BC,D`, исходную тройку и вектор диагонали `a+b+c`.
- `decompose(p,[a,b,c])` возвращает коэффициенты `[x,y,z]` равенства `p=xa+yb+zc`. Компланарная или почти вырожденная тройка вызывает `RangeError`. Ортогональность не требуется; нулевой вектор даёт `[0,0,0]`.

Коллинеарность, компланарность и проверки направления используют нормированные векторы с угловым допуском `EPS=1e-10`, поэтому не зависят от единиц длины. Почти зависимый базис отклоняется для защиты от неустойчивых коэффициентов. Детерминанты и нормали являются деталями внутренней реализации; в учебном тексте серии 04 они не вводятся. Координатный метод и скалярное произведение относятся к серии 05.

## Изображение

Существующий `spatial-scene.js` получает обычную пространственную сцену с именованными точками. Новый primitive:

```js
{
  type:'vector',points:['A','B'],vectorId:'a',label:'a⃗',
  style:'emphasis',labelOffset:[0,-10]
}
```

Стрелка размещается у второго конца; нулевой вектор обозначается кольцом без стрелки. Подпись находится около середины и сдвигается `labelOffset` в экранных единицах. ID сохраняется в SVG как `data-vector-id`; label добавляется через `textContent`. `segment`, `ray`, `line`, `plane` и их прежнее поведение сохраняются. Скрытые рёбра задаются явно. Проекция не служит источником математической длины или отношений векторов.

`grade11-vector-scenes.js` регистрирует `window.KTP_G11_VECTOR_SCENES`: 12 сцен уроков 33–44. Поле `vectors` содержит вычисленные направленные отрезки, `math` — исходные точки и проверяемые отношения. Поурочное подключение далее использует прежний `spatialFigure` / `lesson-spatial.js`; тематическая страница — `spatialScenes`. Порядок загрузки: ядро → реестр сцен → контент/адаптер → spatial renderer.
