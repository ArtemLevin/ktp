# Geometry scene layer KTP 3.0

`geometry/geometry-scene.js` — общий zero-build renderer статических учебных SVG-чертежей для линий геометрии.

Для стереометрии используется `spatial-scene.js`; для тел вращения 11 класса работают `revolution-math.js` и `revolution-scene.js`. Их модель, ограничения и подключение описаны в [REVOLUTION_RENDERING.md](REVOLUTION_RENDERING.md). Базовый fixture содержит пять сцен серии 01, а [fixture объёмов](fixtures/grade11-revolution-volume.html) — 11 reusable-сцен уроков 22–32 и математические проверки шаровых частей, сечений и масштабирования.

## Назначение

Слой предназначен для чертежей, которые являются частью объяснения или условия: точки, прямые, лучи, отрезки, углы, окружности, многоугольники и стандартные геометрические отметки. Исследовательская интерактивность остаётся в `labs/`.

Контент хранит только данные сцены:

```js
geometryScenes:{
  example:{
    title:'...',
    ariaLabel:'...',
    viewBox:[0,0,420,220],
    points:{A:[60,160],B:[340,160]},
    objects:[
      {type:'segment',points:['A','B'],ticks:1}
    ],
    caption:'...'
  }
}
```

В теоретическом HTML размещается placeholder:

```html
<span data-geometry-scene="example"></span>
```

После общего `topics/topic-page.js` подключается `geometry/geometry-scene.js`, который заменяет placeholder на адаптивный SVG.

## Использование в поурочном слое

Для `lessons/` данные сцен хранятся в `window.KTP_LESSON_SERIES.geometryScenes`, а у блока теории или разобранного примера указывается поле `figure`.

`geometry/lesson-geometry.js` является тонким reusable-адаптером: после общего `lessons/lesson-page.js` он добавляет placeholders в уже отрисованные карточки урока и передаёт scene registry общему `geometry-scene.js`. Геометрические серии поэтому используют тот же lesson renderer, что и алгебраические и арифметические линии, без копирования UI.

Рекомендуемый порядок подключения на странице геометрического урока:

```html
<script src="../../lesson-page.js"></script>
<script src="../../../geometry/lesson-geometry.js"></script>
<script src="../../../geometry/geometry-scene.js"></script>
```

## Поддерживаемые primitives

- `segment` — отрезок; опции `ticks`, `parallel`;
- `line` — прямая через две заданные точки, автоматически продолжаемая до границы `viewBox`;
- `ray` — луч с маркером направления;
- `polygon` — многоугольник;
- `circle` — окружность по центру и радиусу;
- `angle` — дуговая отметка угла;
- `rightAngle` — отметка прямого угла;
- `markEqual` — отметка равных отрезков;
- `markParallel` — отметка параллельности.

Стиль объекта задаётся `style: 'main' | 'aux' | 'emphasis'`.

## QA-инварианты

1. Все точки, на которые ссылается primitive, существуют и имеют конечные координаты.
2. Каждый чертёж имеет `title`/`ariaLabel` и текстовую подпись, достаточную для понимания без цветового кодирования.
3. Чертёж соответствует условию задачи: отметки равенства, параллельности и перпендикулярности ставятся только при заявленном свойстве.
4. SVG использует `viewBox`, поэтому сохраняет масштабирование на мобильном экране и при печати.
5. Статический scene layer не хранит состояние и не дублирует логику цифровых лабораторий.
6. В геометрических уроках `figure` обязан ссылаться на существующий ключ `KTP_LESSON_SERIES.geometryScenes`.
7. Lesson adapter не меняет общий DOM-контракт `lesson-page.js` и должен оставаться безопасным для остальных учебных линий.

## Пространственные векторы

`vector-math.js` и `grade11-vector-scenes.js` образуют модель и 12 сцен уроков 33–44. [Контракт](VECTOR_CONTRACT.md) описывает направленный отрезок, нулевой вектор, перенос, операции, компланарность и разложение по неортогональной тройке. [Fixture](fixtures/grade11-vectors.html) переиспользует `spatial-scene.js`: primitive `vector` добавляет стрелку, id и подпись; нуль отображается кольцом. Вычисления остаются в 3D и независимы от камеры.


Лаборатория [vector-constructor](../labs/11-geometry-atanasyan/vector-constructor/index.html) переиспользует векторное ядро и общий renderer. Модель сохраняет данные независимо от камеры; ползунки управляют переносом, коэффициентами суммы и выходом третьего вектора из плоскости. Release gate: `scripts/qa-grade11-geometry-topic04-release.mjs` и `scripts/qa-grade11-geometry-topic04-release-browser.mjs`.


## Координаты, метрика и движения

`coordinate-math.js` добавляет к векторному ядру скалярное произведение, типы углов, нормированную плоскость, расстояние/проекции, сферу, симметрии, перенос и подобие. `grade11-coordinate-scenes.js` содержит 12 сцен уроков 45–56 и три параметрических состояния лаборатории `coordinate-space/`. Материалы используют общую пространственную проекцию; геометрическая метрика от камеры не зависит.
